## 默认配置结构

组件库的默认配置定义在 `src/packages/default.ts` 文件中，通过 `defaultOlMapConfig` 对象提供全局默认值。该配置主要包含地图服务的API密钥和瓦片图层URL模板，支持天地图（TDT）、百度地图（Baidu）和高德地图（AMap）三种主流地图服务。

配置结构采用类型化方式定义，包含以下核心部分：

- **`tdt`**: 天地图配置，包含 `ak`（访问密钥）以及多种图层类型（如 `Normal`、`Satellite`、`Terrain` 等）的URL模板。
- **`baidu`**: 百度地图配置，同样包含 `ak` 和各类图层的请求地址。
- **`amap`**: 高德地图配置，仅包含图层URL模板，无密钥字段。

在应用初始化时，可通过 `app.use()` 方法传入自定义配置对象来覆盖默认值。系统使用对象扩展（`...`）语法合并配置，确保未指定的字段仍保留默认行为。

例如，设置天地图密钥和自定义地图中心点与缩放级别的方式如下：

```ts
app.use(Installer, {
  tdt: { ak: 'your-tianditu-api-key' },
  map: { center: [108.93, 34.26], zoom: 10 }
});
```

此机制允许开发者在不修改源码的情况下灵活适配不同项目需求。

## 运行时配置能力

`src/packages/config/index.vue` 组件提供了运行时动态调整地图参数的能力。该组件通过 Vue 的 `provide/inject` 机制将配置上下文注入到整个组件树中，使得子组件可以访问全局配置。

其核心实现逻辑如下：

1. 使用 `withDefaults(defineProps<ConfigProviderContext>(), {})` 定义可接收的配置属性，并设置默认值。
2. 在 `onMounted` 生命周期钩子中调用 `init()` 函数，通过 `provide("ConfigProvide", props)` 将配置数据暴露给后代组件。
3. 使用 `rendered` 响应式变量控制插槽内容的渲染时机，确保配置初始化完成后再渲染子元素。

该组件作为配置注入的容器，允许用户在模板中包裹其他地图组件，并传递运行时配置：

```vue
<OlConfig :map="{ center: [116.4, 39.9], zoom: 12 }">
  <OlMap />
</OlConfig>
```

这种方式实现了配置的动态化与组件解耦，提升了灵活性。

## 样式定制机制

组件库提供了多层次的样式定制能力，主要包括通过 `props` 传递样式对象、利用工具函数生成动态样式，以及使用CSS变量或作用域CSS修改外观。

### 通过Props传递样式对象

开发者可通过 `props` 向组件传递样式配置对象，这些对象通常符合 `FeatureStyle` 类型定义，包含 `fill`、`stroke`、`text`、`icon`、`circle` 等视觉属性。

### 工具函数生成动态样式

`src/packages/utils/style.ts` 文件提供了核心样式处理函数：

- **`setStyle(option: FeatureStyle)`**: 主样式构造函数，根据传入的选项创建 `ol/style/Style` 实例。
- **`setText(option: TextStyleOptions)`**: 创建文本样式，支持字体、填充、描边、背景等配置。
- **`setCircleStyle(option: CircleStyleOptions)`**: 创建圆形图标样式。
- **`setFeatureStyle(feature, style, map)`**: 将样式应用到特定要素（Feature），并支持动态样式函数（`styleFunction`）。

这些函数内部使用 OpenLayers 的 `Fill`、`Stroke`、`Text`、`Icon` 等类构建样式对象，并支持默认值回退机制，确保样式完整性。

### CSS变量与作用域CSS

虽然核心样式由JavaScript生成，但组件的容器样式仍可通过CSS控制。例如，在 `src/style.css` 中定义了根样式变量和全局布局规则。开发者可通过覆盖CSS变量或编写作用域样式（`<style scoped>`）来调整组件的非地图部分外观，如控件位置、边距、字体等。

```css
/* 示例：自定义按钮样式 */
.storybook-button--primary {
  background-color: #ff6b6b;
}
```

这种组合方式兼顾了地图要素的动态渲染需求和UI组件的样式灵活性。

## 主题定制可能性

尽管当前代码库未显式实现主题系统，但其架构为创建和应用自定义主题提供了良好基础。开发者可通过以下方式实现主题定制：

1. **封装主题配置对象**：基于 `ConfigProviderProps` 类型定义多个主题配置（如“深色主题”、“白天模式”、“夜间模式”），预设不同的地图服务、样式参数和UI变量。

2. **动态切换主题**：结合Vue的状态管理（如Pinia或Vuex），在运行时切换注入的配置对象，实现主题切换效果。

3. **扩展样式工具函数**：在 `style.ts` 中增加主题感知逻辑，根据当前主题名称返回不同的默认样式值。

4. **CSS变量主题化**：在 `:root` 中定义主题相关的CSS变量（如 `--theme-bg-color`、`--theme-text-color`），并通过JavaScript动态修改 `document.documentElement.style.setProperty()` 切换主题。

通过整合配置注入、动态样式生成和CSS变量，可以构建一个完整的主题系统，使地图组件无缝融入不同风格的应用界面。
